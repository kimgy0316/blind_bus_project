# 기사용 안드로이드 앱 — 1단계

## 설치 및 실행
1. driver_flutter.zip을 압축 해제합니다.
2. 안에 있는 driver_flutter 폴더를 C:\Users\LG\blind_bus_project 안으로 복사합니다.
   최종 위치가 C:\Users\LG\blind_bus_project\driver_flutter\pubspec.yaml인지 확인하세요.
3. 에뮬레이터를 켜고 Android Studio의 새 터미널에서 실행합니다.

```powershell
cd C:\Users\LG\blind_bus_project\driver_flutter
flutter pub get
flutter run
```

여러 기기가 표시되면 설치할 에뮬레이터를 선택합니다.
앱 이름은 `Blind Bus 기사`입니다. 기존 승객 앱과 별도로 설치됩니다.
이 단계에는 Python 서버와 API 키가 필요하지 않습니다.

## 성공 확인
- 버스 번호 747, 차량번호 충북70아1234를 입력하고 저장합니다. 예시 번호이며 실제 운행 차량 확인은 아닙니다.
- 내 운행 차량 화면에 입력한 내용이 표시됩니다.
- 앱을 완전히 종료하고 다시 열어도 유지됩니다.
- 차량 정보 수정 후 저장하면 변경됩니다. 수정 취소 시 기존 값이 유지됩니다.
- 빈 값이나 잘못된 차량번호는 저장되지 않습니다.

## 현재 범위
Android SharedPreferences에 기기별 차량 정보를 저장합니다. 재설치하거나 앱 데이터를 삭제하면 초기화될 수 있습니다.
실제 노선 ID/차량 ID 검증, 서버 등록, 승객 요청 수신, 기사 확인·탑승 완료는 아직 연결하지 않았습니다.
앱에 표시하는 '기기 저장 완료'는 실제 버스와의 연동 완료를 의미하지 않습니다.

## 검증
Dart 정적 분석 통과. Android 실기기에서 재실행 후 저장 유지 확인은 별도로 필요합니다.

자동 위젯 테스트는 Flutter SDK cache/lockfile 접근 권한 제한으로 실행하지 못했습니다. 테스트 코드는 test/vehicle_test.dart에 포함했습니다. APK 빌드 및 설치는 사용자 환경에서 진행해야 합니다.
