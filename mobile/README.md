# 시각장애인 버스 안내 모바일 앱

React Native + Expo 기반 제출용 모바일 앱 프로토타입입니다.

## 실행

```powershell
cd C:\Users\LG\blind_bus_project\mobile
npm install
npx expo start
```

Android는 Expo Go 또는 에뮬레이터로 실행할 수 있습니다.
iPhone은 Expo Go 앱으로 QR 코드를 스캔해 실행할 수 있습니다.

## 구현 기능

- 목적지 입력
- 음성 안내 출력
- 버스 경로 안내 단계 표시
- 실시간 버스 정보 시연
- AI 노선번호 판정 결과 표시
- 기사 알림 mock
